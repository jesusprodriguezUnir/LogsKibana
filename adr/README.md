# Architecture Decision Records (ADR)

Registro de decisiones de arquitectura de LogsKibana. Cada ADR documenta una
decisión relevante, su contexto, las alternativas consideradas y sus
consecuencias. Formato ligero inspirado en el de Michael Nygard.

Estados posibles: `Propuesto`, `Aceptado`, `Rechazado`, `Sustituido por ADR-XXX`.
